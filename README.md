# UmaEasyPlay Lite

우마무스메 게임 편의 도구 — 캡처 / 녹화 / 병합 / GIF / 웹뷰 / 커서 교체 / 육성 분석

---

## ✨ 주요 기능

### 🎮 캡처 · 녹화
| 기능 | 설명 |
|---|---|
| 📷 단일 캡처 | 게임 화면 즉시 캡처 |
| 🔗 스크롤 병합 | 스크롤 캡처 후 자동 이미지 병합 |
| 🔴 녹화 | 게임 화면 MP4 녹화 |
| 🎞️ GIF 생성 | 게임 화면 GIF 녹화 |

### 🌐 웹뷰 · 유틸
| 기능 | 설명 |
|---|---|
| 🌐 웹뷰 | 친구찾기 · 스킬검색 · 상성계산기 · 주자설정 내장 브라우저 |
| 📊 팬수관리 | OCR 기반 팬수 자동 추적 |
| 🖱️ 커서 교체 | 인게임 마우스 커서 커스텀 이미지로 교체 |

### 🏇 육성 분석 도구
| 기능 | 설명 |
|---|---|
| 📈 레이스 분석기 | 스킬 프리셋 기반 레이스 시뮬레이션 / 코스별 분석 |
| 📚 스킬 도감 | 전체 스킬 검색 · CG 분류 · 교집합 분석 · 덱 연동 |
| 📊 마신표 | 스킬별 마신(효과량) 계산 · 코스/각질별 비교 |
| 🏆 캐릭터 랭킹 | 코스별 캐릭터 적성 순위 |
| 🃏 덱 최적화 | 서포트 카드 조합 추천 (7가지 전략 · 미래시 반영) |
| 🧬 인자 설계도 | 6세대 63노드 가계도 · 상성 분석 · 인자 전파 시뮬레이션 |

---

## 🧬 인자 설계도

6세대(육성마 → 현조) 63노드 가계도에서 인자를 설계하고 적성 변화를 시뮬레이션합니다.

| 기능 | 설명 |
|---|---|
| 가계도 | 육성마 / 부모 / 조부모 / 증조 / 고조 / 현조 트리 |
| 캐릭터 선택 | 아이콘 · 적성 · 상성 점수 테이블 |
| 인자 설정 | 노드별 적성 인자 ★1~3 설정 |
| 적성 전파 | 하위 인자 → 상위 적성 자동 반영 (빨강 강조) |
| 드래그앤드롭 | 캐릭터 + 인자 + 서브트리 복사 |
| 프리셋 | 가계도 설정 저장/불러오기 |

## 🚀 처음 설치

| 파일 | 설명 |
|---|---|
| `UmaEasyPlay_lite.7z` | 라이트버전 전체 패키지 (최초 설치용) |

`.7z` 파일을 다운로드 후 원하는 폴더에 압축 해제하여 사용하세요.

> ⚠️ **설치 경로 주의**
> 폴더 경로에 **한글 · 공백 · 특수문자**가 포함되면 오작동할 수 있습니다.
> 예) `C:\Users\홍길동\바탕화면\` ❌
> 예) `C:\Games\UmaEasyPlay_lite\` ✅
> 경로가 `C:\` 바로 아래 또는 영문 경로인지 확인해주세요.

## 🔄 업데이트

### 프로그램 업데이트 (자동 알림)
프로그램 실행 시 새 버전이 있으면 자동으로 알림이 표시됩니다.

### DB 업데이트 (수동)
육성 분석 도구 사용을 위해 최초 1회 DB 업데이트가 필요합니다.

1. 프로그램 실행 → **[🔄 DB 업데이트]** 버튼 클릭
2. 스킬 · 캐릭터 · 서포트 · 코스 데이터 자동 다운로드
3. **이미지 다운로드** — 캐릭터/서포트/스킬 아이콘 다운로드 (선택)

| 파일 | 업데이트 위치 | 설명 |
|---|---|---|
| `UmaEasyPlay_lite.exe` | 프로그램 내 자동 알림 | 라이트버전 업데이트 |
| `webview_host.exe` | 친구찾기 탭 | 웹뷰 호스트 |
| `UmaOCR.7z` | 팬수관리 탭 | OCR 엔진 |

## 📁 폴더 구조

```
UmaEasyPlay_lite/              ← 경로에 한글·공백 없이 설치 권장
  ├── UmaEasyPlay_lite.exe      ← 실행 파일
  ├── UmaData/                  ← 임시 데이터 (자동 생성)
  ├── bin/
  │   ├── webview_host.exe      ← 웹뷰 호스트 (프로그램 내 설치)
  │   └── UmaOCR/               ← OCR 엔진 (프로그램 내 설치)
  ├── json/                     ← 게임 데이터
  │   ├── skills.json
  │   ├── character-cards.json
  │   ├── support-cards.json
  │   ├── racetracks.json
  │   ├── skill_list.json       ← 스킬 프리셋
  │   ├── race_presets/         ← 레이스 프리셋
  │   └── inherit_presets/      ← 인자 설계 프리셋
  ├── images/                   ← 아이콘 (DB 업데이트 시 다운로드)
  │   ├── char_icons/
  │   ├── sup_icons/
  │   └── skill_icons/
  ├── config_lite.ini           ← 설정 파일
  └── version.ini               ← 버전 정보
```

## ⚠️ 주의사항

- Windows 10 / 11 전용
- 처음 실행 시 UAC(관리자 권한) 요청이 발생할 수 있습니다
- 백신 프로그램에서 오탐(false positive)이 발생할 경우 예외 처리 후 사용하세요
- 설치 경로에 한글 · 공백 · 특수문자가 없는지 확인하세요
- 육성 분석 도구 사용 전 **[🔄 DB 업데이트]**를 먼저 실행하세요
